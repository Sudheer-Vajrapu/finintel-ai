# FinIntel AI

Financial document intelligence dashboard for analyzing and visualizing financial data. Supports `.xls`, `.xlsx` files, metrics display, risk analysis, and Q&A.

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- TanStack Query
- React Router
- React Window (for virtualized lists)
- Vite (build tool)

## Setup

```bash
npm install

npm run dev
```

## Scripts

- `npm run dev` — Start dev server
- `npm run build` — Production build
- `npm run preview` — Preview production build
- `npm run lint` — Run ESLint
